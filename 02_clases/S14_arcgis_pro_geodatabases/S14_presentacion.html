QGIS + ArcGIS Pro: La combinación profesional

Un ingeniero o urbanista competente domina ambos ecosistemas: la agilidad y apertura de QGIS para análisis territorial, y la robustez corporativa de ArcGIS Pro para bases de datos empresariales y gobierno.

QGIS (Open Source · .qgz / .gpkg)

Flexibilidad y Algoritmos Abiertos

Potente integración con GDAL, GRASS, SAGA y Python. Licencia libre, sin costo, ideal para análisis ráster, teledetección y prototipado rápido de cuencas.

ArcGIS Pro (Esri · .aprx / .gdb)

Estándar Empresarial e Integridad

Bases de datos masivas (Geodatabases), reglas topológicas estrictas, servidores REST corporativos y trazabilidad contractual en firmas de ingeniería.

Bloque 1 · Arquitectura de Software

La Interfaz y el Proyecto de ArcGIS Pro (.aprx)

El archivo central de trabajo

El proyecto de ArcGIS Pro (.aprx)

A diferencia de los antiguos documentos ArcMap (.mxd), un archivo .aprx almacena múltiples mapas 2D, escenas 3D, layouts de impresión y conexiones a bases de datos en un solo lugar.

Panel Contents (Izquierda)

La tabla de contenido: orden de dibujo de capas, simbología y selección de entidades.

Cinta Ribbon (Superior)

Pestañas contextuales tipo Office (Map, Insert, Analysis, View) que cambian según el elemento seleccionado.

Panel Catalog (Derecha)

El explorador de bases de datos: administra carpetas, Geodatabases, toolboxes y conexiones a servidores de internet.

Bloque 2 · Almacenamiento Espacial

La Arquitectura de la File Geodatabase (.gdb)

El contenedor nativo de Esri

¿Qué es una File Geodatabase (.gdb)?

En el sistema operativo se ve como una carpeta con archivos binarios; en el software funciona como una base de datos relacional espacial de alto rendimiento (hasta 1 TB de capacidad).

Feature Dataset

Contenedor con CRS Unificado

Agrupador temático que obliga a que todas las capas internas compartan el mismo sistema de coordenadas (ej. EPSG:9377). Impide mezclar proyecciones por error.

Feature Class

Capa Vectorial Individual

Tabla espacial de puntos, líneas o polígonos. A diferencia del Shapefile, no tiene límite de 10 caracteres en nombres de columna ni trunca textos.

Tablas y Ráster

Almacenamiento Híbrido

Admite tablas alfanuméricas independientes, catálogos de ráster y reglas de topología corporativa avanzada.

Bloque 3 · Integridad y Calidad

Dominios de Atributo y Subtipos

Blindar la base de datos contra el error humano

Dominios de Atributo: Cero errores de digitación

En proyectos grandes donde 20 personas capturan datos en campo, permitir texto libre destruye las consultas SQL (unos escriben "Gavión", otros "gavion", otros "Gaviones").

Dominios de Valor Codificado (Coded Values)

Listas Desplegables Cerradas

Asocia un código numérico interno a una descripción legible:

  • Código 1 = Dique de contención
  • Código 2 = Gavión escalonado
  • Código 3 = Canal abierto revestido

En campo el operador solo puede seleccionar opciones de la lista.

Dominios de Rango (Range Domains)

Intervalos Numéricos Válidos

Impide ingresar valores físicamente imposibles en campos de ingeniería:

  • Diámetro de tubería: entre 100 mm y 1 500 mm
  • Pendiente de diseño: entre 0.5% y 25%

Si alguien digita 15 000 mm por error, la base de datos rechaza el registro.

Paso a paso técnico

Crear una GDB con dominios en ArcGIS Pro

1

Crear File Geodatabase

Panel Catalog → Clic derecho en carpetas del proyecto → New → File Geodatabase (nombrar: Iguana_Corporativa.gdb).

2

Feature Dataset CTM12

Clic derecho en la .gdb → New → Feature Dataset → Asignar sistema oficial: EPSG:9377 (CTM12).

3

Crear Dominio

Clic derecho en la .gdb → Domains → Crear dominio dom_tipo_obra con valores codificados (1: Dique, 2: Gavión, 3: Canal).

Habilidad 1 · Todos al tiempo en su computador

Práctica en vivo: estructuren su GDB de mitigación

Actividad en vivo (12 minutos)

Construyan la base de datos corporativa para las obras de mitigación de La Iguaná:

  • Creen la File Geodatabase Iguana_Corporativa.gdb con un Feature Dataset en EPSG:9377.
  • Definan un dominio de valores codificados para el material de obra (1: Concreto reforzado, 2: Mampostería, 3: Enrocado).
  • Creen una Feature Class de puntos obras_propuestas con campos: nombre, tipo_obra (asociado al dominio) y costo_estimado.
  • Digitalicen 3 puntos de prueba en la cuenca y comprueben cómo el atributo se selecciona desde una lista desplegable blindada.

Bloque 4 · Geoservicios Corporativos

Consumo de Servicios ArcGIS Server REST

El estándar de publicación de datos del Estado

Servicios ArcGIS Server REST (MapServer y FeatureServer)

En lugar de descargar shapefiles desactualizados, los ingenieros se conectan en tiempo real a los servidores de las entidades públicas.

MapServer (Imágenes de Mapa)

Servicio de Visualización Rápida

El servidor renderiza el mapa en sus máquinas y envía teselas gráficas al software. Extremadamente rápido, ideal para ortofotos y capas base densas.

FeatureServer (Vectores Crudos)

Servicio Vectorial Interactivo

Envía las geometrías y la tabla de atributos completa a su cliente. Permite hacer selecciones por atributos, geoprocesamiento y exportación local.

Paso a paso técnico

Conectar un servidor ArcGIS Server en ArcGIS Pro / QGIS

1

Nueva conexión de servidor

Panel Catalog → Clic derecho en Servers → New ArcGIS Server Connection (en QGIS: menú del explorador ArcGIS REST Servers).

2

Pegar URL del servicio

Pegar el endpoint REST institucional del AMVA o GeoMedellín (ej. https://geomedellin.medellin.gov.co/arcgis/rest/services).

3

Explorar y arrastrar capas

Desplegar carpetas temáticas (Planeacion, Amenazas, Riesgo, Hidrografia) y arrastrar la capa al mapa.

Habilidad 2 · Todos al tiempo en su computador

Práctica en vivo: consuman la cartografía oficial REST

Actividad en vivo (10 minutos)

Bloque 5 · Interoperabilidad

Migración entre GeoPackage y Geodatabase

Puente entre mundos

Migración bidireccional de datos

En la práctica profesional, un cliente les entregará una .gdb de Esri y ustedes procesarán en QGIS, o viceversa.

De QGIS a ArcGIS Pro

Importar GeoPackage

En ArcGIS Pro, abran la herramienta Feature Class to Geodatabase. Seleccionen las capas del archivo .gpkg de La Iguaná e impórtenlas directamente al Feature Dataset de su .gdb.

De ArcGIS Pro a QGIS

Lectura Nativa de GDB

QGIS cuenta con el driver OpenFileGDB integrado: pueden arrastrar cualquier carpeta .gdb al panel de capas de QGIS y leer todas sus Feature Classes sin necesidad de tener licencia de Esri instalada.
